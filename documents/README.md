# Sơ đồ dự án Student Wallet

Các sơ đồ được lưu ở định dạng Mermaid để nhóm có thể chỉnh sửa:

- `use-case.mmd`: tác nhân sinh viên và các nghiệp vụ chính.
- `erd.mmd`: mô hình dữ liệu quan hệ.
- `deployment.mmd`: kiến trúc triển khai Docker Compose.

Có thể mở các file bằng VS Code có hỗ trợ Mermaid hoặc Mermaid Live Editor để xem và xuất ảnh.
